Простая консольная программа калькулятор на Python

Это простой калькулятор, который выполняет основные арифметические операции: сложение, вычитание, умножение и деление.

## Как использовать

1. Скопируйте исходный код в файл с расширением `.py`, например, `calculator.py`.
2. Запустите файл через командную строку или терминал:
Следуйте инструкциям на экране: введите операцию и числа.

Возможности

Сложение (+)
Вычитание (-)
Умножение (*)
Деление (/)

Важно

Деление на ноль не допускается и выводится сообщение об ошибке.==
